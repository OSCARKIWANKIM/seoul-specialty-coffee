# 서울 스페셜티 커피 상권 분석: 군자 테이스팅 룸

향후 3년 안에 뜰 서울 스페셜티 커피 상권 3곳(1순위 군자, 2순위 문래, 3순위 약수)을 지표 5개로 선정하고, 1순위 군자에 낼 매장 컨셉과 타겟 고객을 제안하는 웹사이트입니다.

- 사이트: https://oscarkiwankim.github.io/seoul-specialty-coffee/
- 데이터: 서울시 상권분석서비스, 서울 열린데이터광장, LOCALDATA 휴게음식점 인허가, 유튜브 검색 결과 (기준 2026년 2분기)

## 페이지 구성
1. "뜬다"의 정의와 지표 5개, 기준값 (성수 도약기 보정)
2. 후보 3곳 지표 분석
3. 1순위 군자 논의 (근거와 리스크, 철회 조건)
4. 타겟 고객과 매장 컨셉 "군자 테이스팅 룸"
