# 스페셜티 커피 신규 상권 발굴 – 상권 부상 지수 (Handoff)

> 작성일: 2026-10-18 · 목적: Claude Code에서 데이터 수집·점수화 자동화를 이어가기 위한 컨텍스트 정리

## 1. Background

- **Client**: 스페셜티 커피 업체. 서울 내 신규 출점 상권 탐색
- **대상 정의**: 서울시 내 최근 5년간 상권은 일부 존재했으나 **대량 유입이 없던 권역** (동 단위)
  - 내국인 유입
  - 외국인 유입 (명동 → 연남 → 성수의 **후발 주자** 개념)
- **진입 타이밍 원칙**: 상권 라이프사이클 중 **2단계(개척자 진입기)** 가 최적
  1. 구조적 조건 형성 → 2. 개척자 업종 진입 → 3. 확산(유동·매출·임대료 상승) → 4. 정점(프랜차이즈·기사 폭증·개척자 이탈)

## 2. 레퍼런스: 한남동·연남동 부상 driver

| | 연남동 | 한남동 |
|---|---|---|
| 촉발 | 홍대 임대료 상승 spillover | 이태원·경리단 포화 spillover |
| 핵심 동력 | 공공 인프라 (공항철도·경의선 2010~12, 경의선숲길 2015~16) | 민간 자본 (리움·블루스퀘어·현대카드 라이브러리, 플래그십, 한남더힐·나인원한남) |
| 공간 | 저층 단독·다가구 → 1층 상가 전환 용이 | 대사관·부촌 + 고급 주거 배후 |
| 주력 업종 | 소자본 F&B, 카페 | 플래그십, 갤러리, 파인다이닝 |

공통 driver: **포화 상권 인접 + 임대료 격차 + 전환 가능한 건물 재고 + 촉매(인프라/앵커)**

### 설계 노트 (리뷰 과정에서 나온 쟁점)
- 신규 카페 허가·업종 전환은 상권 분석 관점에서 **공급 신호**에 가까움 (현재는 수요로 분류)
- 지도 앱 검색량(구글·네이버·카카오)·IG 검색량은 **비공개** → 리뷰/저장 수 증가율, 해시태그 수로 대체
- **기사는 후행 지표** → 많을수록 감점 (정점 경고)
- 절대량 대신 **증가율 + 성수 대비 정규화** 사용
- **UGC 대비 기사 비율** (기사 ÷ (IG+블로그)): 낮을수록 초기 단계
- 추가 검토 driver: 앵커 시설, K-콘텐츠 노출, 숙박 공급, 재개발·규제 리스크, 해외 플랫폼(샤오홍슈, 구글맵 외국어 리뷰)
- 클라이언트 특화 기준: 반경 500m 내 스페셜티 경쟁 상한(예: 2~5곳), 평일 배후 수요(주거·직장·대학), 선점 효과
- 백테스트 권장: 연남(2014~16), 성수(2016~19), 신당(2021~23)에 지표 적용해 6~12개월 선행성 검증

### 3-4. 성수·연남·홍대·약수 비교 (상권분석 + 인허가)

- **홍대입구역**: 카페 183→215곳(2025Q1 정점 235 이후 감소), 점포당 월매출 3,430만→5,480만원, 20~30대 59.4%→62.3%. 포화 후 정체·감소.
- **약수역**: 카페 15→22곳, 점포당 월매출 3,320만→1,020만원(-69%), 20~30대 32.6%→34.7%, 변동지표 정체.
- **성수동카페거리**: 카페 30→43곳, 점포당 월매출 1,330만→3,490만원, 객단가 6,336→10,305원.
- **성수 인허가(성수1·2가 반경)**: 영업중 카페 2017년 74 → 2020년 105곳.
- 성수는 2021년을 "뜬 시점"으로 가정하기로 했습니다.

### 3-5. "뜬다" 정의와 지표 5개

> 개인 카페가 서울 상위권 속도로 늘고, 20~30대 유동 비중이 높고 오르며, 아직 성수·홍대만큼 포화되지 않았고, 서울시 상권변동지표가 다이나믹·확장인 상권.

| # | 지표 | 성격 | 기준 |
|---|---|---|---|
| ① | 개인 카페 영업중 증가 (인허가, 3년) | 선행 | 순증 +25곳 이상, 증가율 +41% 이상 (서울 상위 10%·25%) |
| ② | 20~30대 유동 비중 | 선행 | 44.5% 이상, 2년 변화 +1.5%p 이상 (상위 25%) |
| ③ | 점포당 월매출 | 확인 | 2년 +24% 이상 확인, -10% 이하 탈락 |
| ④ | 객단가 | 확인 | 2년 +13% 이상 |
| ⑤ | 상권변동지표 | 필터 | 다이나믹·확장 통과, 정체·축소 탈락 |

성수 보정: 2017→2020 인허가에서 +31곳(상위 6%), +42%(상위 24%), 2021Q1→2023Q1 20~30대 비중 43.8~51.5%(+2.7~3.6%p, 상위 6~13%). ③④는 성수 도약기에 선행하지 않아 확인용으로 내렸습니다. 이 기준은 성수에 맞춘 보정이며 예측 검증이 아닙니다.

### 3-6. 후보 3곳 검토

| 지표 | 군자역 | 문래예술촌 | 약수역 |
|---|---|---|---|
| ① 개인 카페 증가 | 과거 +89%, 최근 -6% | 영업중 +1% | -3% |
| ② 20~30대 비중 | 45.2% (0.0%p) | 34.3% | 34.7% (+1.5%p) |
| ③ 점포당 월매출 | 4,610만 (+38.2%) | -12.3% | -52.7% |
| ④ 객단가 | +11.7% | +4.1% | -11.2% |
| ⑤ 상권변동지표 | 상권확장 | 상권확장 | 정체 |

- **결론(팀 합의): 1순위 군자, 2순위 문래, 3순위 약수.** 군자는 매출 확인(③)과 변동지표(⑤)를 동시에 통과한 유일한 후보입니다.
- **군자의 약점(그대로 표기):** 최근 개인 카페 -35%(11곳), 20~30대 비중 변화 0.0%p. 리스크 한 가지는 "개인 카페 감소의 원인이 수요 부족일 수 있다"이며, 점포당 월매출 증가율이 두 분기 연속 둔화하면서 개인 카페가 추가로 감소하면 철회합니다.
- 약수는 유튜브에서 "성수 다음"이라는 영상이 약 91만 회 조회되지만 카드 매출은 반대로 움직입니다. 크리에이터 담론과 실제 소비의 괴리라는 별도 인사이트입니다.
- **기준 상권(성수·연남·연희)과 비교:**

| 연희 | 67→81 (+21%) | 101→103 (+2%) |

### 3-7. 서울 전체 스크리닝 (지표 기준)
2024Q2→2026Q2에서 20~30대 비중·변화, 개인 카페 순증, 점포당 매출 수준, 변동지표로 거른 상위권은 어린이대공원역 3번, 경희대삼거리, 마포FM, 경동고등학교, 능동우편취급국, 서연중학교, 신림역 순입니다. 대학가 편향이 있고, 마포FM·경동고는 위치를 확인하지 못했습니다.

### 3-8. 소셜 지표 (미완)
- **유튜브**: "{동네} 카페" 상위 약 80편의 중앙 조회수는 성수 29,377 / 홍대 4,154 / 연남 1,120 / 약수 670 / 군자 538 / 연희동 502 / 신림 434 / 문래 355 / 회기 306 / 어린이대공원 220입니다. 날짜 정렬이 적용되지 않아 업로드 증가율은 계산하지 못했습니다.
- **인스타그램**: 해시태그 페이지 오류와 크롬 탭 멈춤으로 측정하지 못했습니다.

### 3-9. 매장 컨셉 (팀 확정안): 군자 테이스팅 룸

- **한 줄 소개:** 커피만 12년 판 느좋부부 사장이 운영하는 핀터레스트 감성 소규모 커뮤니티형 카페
- **인테리어:** 망원 빈티지샵에서 팔 것 같은 우드톤의 깔끔한 테이블, 군데군데 따뜻한 조명, 깔끔하고 포근한 카페
- **커피:** 낮에는 동네 에스프레소 바, 저녁에는 예약제 커피 코스. 군자 테이스팅 룸
- **디저트:** 카다멈 번을 메인으로 한 이색 베이커리 3종 이내. 매일 솔드아웃될 정도로 소량만 판매
- **음악:** Yusuf Dayes 같은 플레이리스트
- **사장님 느낌:** 타투 3개 안팎, 콧수염 또는 턱수염 중 하나, 안경, 아메카지. 공동 운영자(와이프)는 섬세한 인상으로 사장님과 대비
- **직원 복장:** 카페 굿즈 티셔츠를 직원복으로 사용
- **기타:** 커스텀 원두, 에코백, 스티커 판매

주의: "12년"은 스토리 설정이라 실제 경력과 다르면 홍보 문구로 쓰지 않습니다. 외모 이미지는 비주얼 무드로만 쓰고 채용 조건으로 삼지 않습니다.
